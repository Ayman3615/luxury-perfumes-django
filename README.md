# 🛍️ Luxury Perfumes (عطور القدس) - E-Commerce Web Application

A full-featured, modern E-commerce platform built with **Django (Python)** and styled with responsive UI, designed specifically for luxury perfumes, customized fragrance blends, and bundle products.

---

## 🚀 Key Features

* **🧠 Advanced AI Integration:**
  * **AI Payment Proof Validation:** Validates bank transfer/receipt screenshots automatically using Google's GenAI model.
  * **Smart AI Perfume Finder:** Recommends the best fragrances based on user preferences.
* **🛍️ E-Commerce Core:**
  * Multi-size pricing (30ml, 50ml, 100ml) and custom product variants.
  * Product bundles and special discounted sets.
  * Shopping cart, wishlist, and secure checkout process.
  * Discount coupons and promotional system.
* **📦 Complete Management Dashboard:**
  * Manage orders, products, customers, and customer reviews.
  * Print invoices and generate WhatsApp order messages directly.
  * Automated abandoned cart email notifications.
* **📱 Native Mobile Experience:**
  * Responsive design featuring a mobile bottom navigation bar (App-like feel).
  * Multi-language support (Arabic & English) with auto-translation in models.

---

## 🛠️ Tech Stack

* **Backend:** Python, Django
* **Database:** SQLite (Development / Production ready)
* **Frontend:** HTML5, CSS3, JavaScript, Responsive UI
* **Deployment:** PythonAnywhere
